# Repository Logo Design

## Goal

Create a repository logo for `plex-octotuner` and add it to the README.

## Approved Direction

- clean modern visual style
- wordmark plus icon lockup
- octopus as the base motif
- bridge shape included clearly
- tuner or signal behavior visible in the mark
- compact badge-like icon
- octopus arms should read as stream or signal sources

## Chosen Concept

Use the refined Bridge Badge direction:

- rounded octopus head in orange
- dark bridge arch above the head
- compact vertical tentacles below
- center tentacles contain small signal nodes to imply stream output
- dark blue wordmark to the right of the icon

## Delivery Format

- SVG asset committed to the repository
- README integration near the project title so GitHub renders the logo prominently

## Non-Goals

- no mascot-heavy illustration
- no photoreal or textured rendering
- no dependency on external image hosting
